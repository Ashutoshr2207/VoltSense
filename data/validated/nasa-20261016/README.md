# Validated NASA discharge prefixes

Generated by ml-service/convert_nasa.py from the preserved local MATLAB corpus. These are NASA-attributed observations, not the synthetic UI demo. See [quality report](../../../docs/battery-quality-report.md) and [evaluation](../../../docs/nasa-evaluation-report.md).

validated_cycles.csv retains raw Ah capacities and source identifiers for 929 cycles from 14 batteries. The quality manifest audits all 34 raw batteries; conversion-summary.json records exclusions/censoring. split-manifest.json freezes battery partitions before fitting. Do not hand-edit rows, rebase cycles, interpolate gaps, or regenerate this experiment split after inspecting test results.

Use sample_data/owner_1.csv for the UI demo. This multi-battery training export is not that synthetic upload.
